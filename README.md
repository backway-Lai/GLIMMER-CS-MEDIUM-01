# 模块一

1. 十进制211对应的二进制为$11010011$。

2. 二进制 10110110 对应的十进制表示为$182$。

3. 根据十进制转二进制规则不难知道，二进制中每一位数都是$m*2^n$，其中n>=0。故我们只需看二进制表示下第一位数是0还是1即可：第一位数是0时代表十进制下这个数全由偶数加法得到，则这个数也是偶数；第一位数是1时代表十进制下这个数全由偶数加法再加一得到，则这个数是奇数。

# 模块二

1. 
    - `unsigned char res1 = a & b`：结果为00001000，即8。按位与运算含义为同为1时结果为1，否则结果为0，因此这里只有第四位结果为1。
    - `unsigned char res2 = a | b`：结果为00011101，即29。按位或运算含义为同为0时结果为0，否则结果为1，因此这里a或b中含1的位结果里都为1。
    - `unsigned char res3 = a ^ b`：结果为00010101，即21。异或运算含义为相同为0、不同为1，因此这里不论是同为1还是同为0输出结果都是0，而不同时则必为1。
    - `unsigned char res4 = (a << 2) | (b >> 1)`：结果为00111100，即60。首先`a << 2`代表左移两位，即将$00001100$移为$00110000$，同理，`b >> 1`代表右移一位，即将$00011001$移为$00001100$，最后再用按位或获得答案。

2. 对于确认某位数上结果的函数，我选择先将这个数在$2^n$以上的部分去掉，只留下较小的部分。并让剩下的部分除以$2^{n-1}$，根据整型运算的取整规则，可以得到预期结果。

3. 对于修改某位数上的结果，我选择先分出四种情况讨论：当修改值t与原本值就相等时，依题意可以直接原数输出；当原数为0而t为1时，可以理解为对原数加上$2^{n-1}$；当原数为1而t为0时，可以理解为对原数减去$2^{n-1}$。

4. 对于找出二进制下第一个1的函数，我采用了更传统的位运算方式。在前面的函数中我使用的更多是求余，这道题我使用求余显然会更麻烦，不如用传统位运算：即将目标位移到第一位，与1做按位与，这样可以很直接的看出目标位的数值。其实运用这个思路前两道题也可以很容易做出，而在这题中只需要引入一个计数就可以找到目标位的位置了。

5. 区间[a,b]中做&实际上只用保留二进制表示中从最高位开始相同的部分，其余位全部变成0。这么做的原因是不同的部分一定会经过0，那么按位与后一定会留下0的结果，而从最高位开始相同的部分中的1可以始终相同不会改变，那么按位与后一定会留下1的结果。

6. 思考题：
    - 逻辑运算一般是对真假的运算，考虑的是0或1；而位运算是对二进制的数值进行的运算，考虑的是数值。
    - 性质：第一个是按位与、按位或、按位异或都满足分配律；第二个是同一个数异或两次，相当于没有改变；第三个是按位与和按位取反结合可以实现对特定位的清零。
    - 算术右移对应有符号数，因为负数需要右移后依旧有负号，因此会使用补码保证右移后数值与符号同时满足预期；而逻辑右移对应无符号数，即补0即可，结果也就相当于除以$2^{n-1}$

# 模块三

**字符串交集检测**：
1. 首先这道题必须解决的是识别字符的问题，这点我们可以用字符自带的编码值解决。而为了避免编码值太大导致后续左移操作未定义，我们可以用小写字母之间的间距解决，即代码中的`c - 'a'`。

2. 其次就是如题意将字符信息录入mask，而这可以通过对1u的左移实现，左移位数就是字符的相对距离决定，最后再做按位或赋值运算，将1的信息录入mask。

3. 最后即是将两个mask的比较，显然可以通过按位与决定。如果有相同字符则按位与后结果不为零，否则必为零，这样我们就可以输出结果了。[^1]

[^1]:实际上这题我被字符串的识别卡了一会，因为我不太能理解如何将abc这样的字符转变为位数信息，但显然编码值给出了非常好的解决方案。字母表中每个字母已经按顺序排好，只需要用其相对位置就可以将字符转为数字进行位运算。

**N皇后问题**：
1. 首先在脑子里想象出一个国际象棋棋盘[^2]，很显然这几个皇后不可以放在同排或同列，因此也就是每排或每列各一个。

2. 当我们从上往下研究每一行皇后摆法时，显然下一行的可能摆法取决于上一行，因此我们考虑使用递归来为每一行做判断。

3. 此时我们希望表达出格子不可使用的状态，而使用二进制数字来表达可以完美与其他变量配合，实现通过位运算不断找出当前行可用的格子。

4. 最后我们再完善函数需要的参数，可以发现对于研究当前行的函数需要知道行数和三个状态变量，将这三个参数通过值传递就可以完成整个函数的递归。[^3]

# 模块五

**广度优先搜索 (BFS) 与位运算寻路**：
1. 跟之前的N皇后问题一样，我们应该先量化整个问题中的变化量，即节点（当前节点、墙壁、起点终点、下一节点等等）、行列坐标、行列代表的顺序等等。

2. 在已有的代码上，框架大致为：
    - 第一，需要用数组队列完成不断向前探路的过程。
    - 第二，记录最短路径的方法是记录到达每个节点所用的步数。
    - 第三，使用位运算表示墙壁和已访问节点（与节点编号相关）。
    - 第四，使用两个方向数组的组合实现行列的变化。最后，代码的基础逻辑为每次找当前节点周边的节点，第一个找到终点的必然是最短步数（不要求记录路径）。

3. 在补全代码中，大致有几个关键点：
    - 第一，四个条件的判断。痛过条件判断了不成立和结束的情况。
    - 第二，对行列的运用。行列的运用直接表示了节点间的位置关系，将抽象的编号转化为有形的行列，从而可以找到建立节点的连结（同时满足了出界判断）。
    - 第三，队列的运用。每个节点被front处理时会马上带来相邻的几个节点，而这几个节点可以视为同阶的，因为他们的`dist`是相同的，所以谁先被front处理没有区别，只需要找到第一个到终点的就可以了。[^4]
